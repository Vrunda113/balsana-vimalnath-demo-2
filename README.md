# Balsana Vimalnath Tirth — Cinematic Demo V6

Open `index.html` in Chrome/Edge.

## V6 changes
- Uses the supplied `dm1.png` concept as the inner hero visual.
- Uses the supplied Balsana Tirth logo in the real navigation and footer.
- Keeps the V5 seamless stone wall + fracture direction.
- Hero uses a virtual scroll gate: fast wheel/trackpad scrolling cannot skip the stone-breaking sequence.
- The document itself is locked until the reveal reaches 100%.
- Navbar is hidden during the reveal and fades in only at the final stage.
- A small landing-frame hold lets the completed reveal register before normal page scrolling begins.
- Mouse wheel, keyboard, and touch swipe are supported.

No build step is required; this is a static HTML/CSS/JS demo.
